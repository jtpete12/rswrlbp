OSRS endpoints, and what each one costs

Every endpoint an Old School RuneScape plugin, app or extension is likely to read, annotated with the load it puts on whoever serves it and how long you may cache the answer. Part of osrs-plugin-review.

Set a User-Agent

The one hard requirement the wiki states. These defaults are blocked before your code runs: python-requests, Python-urllib, Apache-HttpClient, RestSharp, Java/{version}, curl/{version}. A bare HttpURLConnection sends the Java one.

Never loop a bulk endpoint

Omitting id on /latest costs the wiki about 100× less than fetching items one at a time. Their wording: “don't hit us with 3700 API requests”.

Cache the misses too

A lookup that fails and stores nothing re-pays its full cost every time. The keys that never resolve are asked for most often, because nothing records that the answer is no.
